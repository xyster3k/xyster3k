## Границы и сопровождение

Текущий профиль показывает сводку за год; временной ряд и все ветки описаны как варианты расширения. Исходный генератор сохраняет флаг неполноты поиска коммитов; для строгой проверки PR потребуется аналогичный флаг. Эти свойства явно отмечены в руководстве.

Для переноса в новый аккаунт владелец задаёт `GH_METRICS_TOKEN` с нужным охватом. Текущий профиль такого действия не требует: ежедневный сбор работает. Для повторной сборки архива включить шесть файлов канонической папки под корнем `github-profile-metrics/`, затем проверить совпадение содержимого и установленной копии.

Изменения документации, архива и `.agents/skills/` текущий сбор метрик по событию push не запускают. Публикация комплекта выполняется обычным commit и push в `main` с последующей проверкой файлов GitHub.
