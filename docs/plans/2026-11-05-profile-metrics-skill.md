# Инструкция и скилл для страниц GitHub

## Запрос

Подготовить переносимый файл с подробной инструкцией и скилл для создания страниц по образцу профиля xyster3k. Сохранить механики обновления активности, учёта публичных и приватных репозиториев и защиты закрытых сведений. Дизайн оставить на усмотрение автора страницы. Проверить действующую страницу.

## План

1. Прочитать инструкции, предыдущие планы, историю реализации, генератор и сценарий GitHub Actions. Сверить их с опубликованными файлами и последними запусками.
2. Создать переносимый скилл, подробное руководство и исходные шаблоны. Описать охват токена, архивы, источники чисел, периодическое обновление, историю показателей и диагностику.
3. Проверить структуру скилла, работу шаблона на контрольных данных, ссылки и русский текст. Установить скилл локально, собрать архив, сохранить запись сеанса, отправить изменения в репозиторий и проверить доступность файлов.

## Принятые решения

- Страница представляет собой README профиля GitHub, репозиторий `xyster3k/xyster3k`.
- Основа инструкции должна соответствовать проверенному коду. Расширения для графиков и полного охвата помечаются отдельно.
- Действующий генератор и оформление профиля сохраняются.
- Каноническая переносимая копия скилла хранится в `.agents/skills/github-profile-metrics/`, установленная копия в `/home/node/.codex/skills/github-profile-metrics/`.
- В архив входят руководство, скилл и шаблоны, пригодные для другого аккаунта.
